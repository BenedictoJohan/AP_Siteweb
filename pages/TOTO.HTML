Introduction aux commandes de Linux

La ligne de commande (ou terminal) permet de contrôler un système Linux en tapant des commandes au lieu d'utiliser une interface graphique. Elle sert à naviguer dans les fichiers, gérer les droits, installer des logiciels ou administrer un serveur. Maîtriser les commandes de base (ls, cd, cp, grep...) fait gagner beaucoup de temps.

Une commande s'écrit sous la forme commande -option argument. Les options (souvent précédées d'un tiret) modifient le comportement de la commande.

Liste des principales commandes Linux
Commande Action Options courantes
Système de fichiers
pwd Affiche le répertoire courant —
ls Liste le contenu d'un répertoire -l affichage détaillé
-a affiche les fichiers cachés
-h tailles lisibles (avec -l)
-t tri par date
cd Se déplace dans un répertoire cd .. dossier parent
cd ~ dossier personnel
cd - dossier précédent
mkdir Crée un dossier -p crée aussi les dossiers parents
-v affiche ce qui est créé
rmdir Supprime un dossier vide -p supprime aussi les parents vides
touch Crée un fichier vide ou met à jour sa date de modification —
cp Copie un fichier ou un répertoire -r copie un dossier et son contenu
-i demande confirmation avant d'écraser
-v mode verbeux
-p conserve les droits et dates
mv Déplace ou renomme un fichier ou un répertoire -i demande confirmation avant d'écraser
-v mode verbeux
-n n'écrase jamais
rm Supprime un fichier ou un répertoire -r supprime un dossier et son contenu
-f force sans confirmation
-i demande confirmation
Attention : suppression définitive !
ln Crée un lien vers un fichier ou un dossier -s crée un lien symbolique
find Cherche un fichier dans l'arborescence -name "*.txt" par nom
-type f fichiers / -type d dossiers
-size +10M plus de 10 Mo
-mtime -7 modifié depuis moins de 7 jours
locate Recherche rapide d'un fichier par son nom (via une base de données) -i ignore la casse
file Indique le type d'un fichier —
stat Affiche l'état d'un fichier (taille, droits, propriétaire, dates) —
tree Affiche l'arborescence sous forme d'arbre -L 2 limite à 2 niveaux
-a affiche les fichiers cachés
diff Compare deux fichiers ligne par ligne -u format unifié
-r compare deux dossiers
which Donne le chemin complet d'une commande —
Manipulation de texte
cat Affiche le contenu d'un fichier -n numérote les lignes
less Affiche un fichier page par page (navigation avec les flèches, q pour quitter) -N numérote les lignes
head Affiche le début d'un fichier -n 5 affiche les 5 premières lignes
tail Affiche la fin d'un fichier -n 5 affiche les 5 dernières lignes
-f suit le fichier en direct (pratique pour les logs)
grep Recherche un motif dans un fichier -i ignore la casse
-r recherche dans les sous-dossiers
-n affiche le numéro de ligne
-v inverse la recherche
-c compte les lignes trouvées
wc Compte les lignes, mots et octets d'un fichier -l lignes
-w mots
-c octets
sort Trie les lignes d'un fichier -r ordre inverse
-n tri numérique
-u supprime les doublons
uniq Supprime les lignes identiques consécutives -c compte les occurrences
-d n'affiche que les doublons
cut Extrait des colonnes d'un fichier -d ":" définit le séparateur
-f 1 choisit le champ n°1
sed Recherche et remplace du texte 's/ancien/nouveau/g' remplace partout
-i modifie le fichier directement
awk Traite un fichier colonne par colonne '{print $1}' affiche la 1re colonne
-F ":" définit le séparateur
tr Remplace ou supprime des caractères -d supprime les caractères
'a-z' 'A-Z' passe en majuscules
tee Écrit dans la sortie standard et dans un fichier en même temps -a ajoute à la fin du fichier
echo Affiche un texte dans le terminal -n sans retour à la ligne
-e interprète les caractères spéciaux (\n, \t)
nano Éditeur de texte simple dans le terminal Ctrl+O enregistrer
Ctrl+X quitter
Disques et partitions
df Affiche l'espace disque libre et utilisé -h tailles lisibles (Go, Mo)
-T affiche le type de système de fichiers
du Affiche l'espace occupé par des fichiers ou dossiers -h tailles lisibles
-s total uniquement
--max-depth=1 limite la profondeur
lsblk Liste les disques et partitions -f affiche aussi le système de fichiers
blkid Affiche l'UUID et le type des partitions —
fdisk Gère les partitions d'un disque -l liste les partitions
mkfs Crée un système de fichiers sur une partition -t ext4 choisit le type de système de fichiers
mount Monte une partition dans l'arborescence -t type de système de fichiers
-o ro montage en lecture seule
umount Démonte une partition -f force le démontage
fsck Vérifie et répare un système de fichiers -y répond « oui » à toutes les questions
dd Copie des données bloc par bloc (clonage de disque, création de clé USB bootable) if= fichier source
of= fichier destination
bs=4M taille des blocs
Utilisateurs et droits
whoami Affiche le nom de l'utilisateur courant —
id Affiche l'UID, le GID et les groupes d'un utilisateur -u uniquement l'UID
-g uniquement le GID
who Liste les utilisateurs connectés —
useradd Ajoute un utilisateur -m crée le dossier personnel
-s /bin/bash définit le shell
-G ajoute à des groupes
usermod Modifie un compte utilisateur -aG groupe ajoute à un groupe
-L verrouille le compte
-U déverrouille le compte
userdel Supprime un utilisateur -r supprime aussi son dossier personnel
passwd Change le mot de passe d'un utilisateur -l verrouille le mot de passe
-e force le changement à la prochaine connexion
groupadd Crée un groupe —
groups Affiche les groupes d'un utilisateur —
chmod Change les droits d'un fichier ou d'un dossier -R applique récursivement
755 rwx pour le propriétaire, r-x pour les autres
u+x ajoute le droit d'exécution au propriétaire
chown Change le propriétaire d'un fichier -R applique récursivement
user:groupe change propriétaire et groupe
chgrp Change le groupe propriétaire -R applique récursivement
su Change d'utilisateur - charge l'environnement de l'utilisateur
sudo Exécute une commande avec les droits d'un autre utilisateur (root par défaut) -u user choisit l'utilisateur
-i ouvre un shell root
umask Définit les droits par défaut des nouveaux fichiers —
Processus et mémoire
ps Liste les processus aux tous les processus, avec détails
-ef format complet
top Affiche les processus en temps réel (CPU, mémoire) q quitter
k tuer un processus
htop Version plus lisible et interactive de top (à installer) F9 tuer un processus
F10 quitter
kill Envoie un signal à un processus (via son PID) -15 arrêt propre (par défaut)
-9 arrêt forcé
killall Tue tous les processus portant un nom donné -9 arrêt forcé
pidof Donne le PID d'un processus —
jobs Liste les tâches en arrière-plan du terminal —
bg / fg Passe une tâche en arrière-plan / la ramène au premier plan & en fin de commande lance directement en arrière-plan
nohup Lance une commande qui continue après la fermeture du terminal —
nice / renice Définit / modifie la priorité d'un processus -n 10 priorité plus basse
free Affiche la mémoire utilisée et libre -h tailles lisibles
-m en Mo
uptime Affiche depuis quand la machine est allumée et la charge système -p format court
Réseau
ping Teste la connexion vers une machine -c 4 envoie 4 paquets seulement
-i 2 intervalle de 2 secondes
ip Affiche et configure les interfaces et routes réseau a (addr) adresses IP
r (route) table de routage
link état des interfaces
ifconfig Affiche la configuration réseau (ancienne commande) -a affiche toutes les interfaces
hostname Affiche ou modifie le nom de la machine -I affiche les adresses IP
ss Affiche les connexions et ports ouverts -t TCP / -u UDP
-l ports en écoute
-n affichage numérique
-p affiche le processus
netstat Affiche les connexions réseau (ancienne commande, remplacée par ss) -tulnp combinaison courante
traceroute Affiche le chemin parcouru jusqu'à une machine -n sans résolution de noms
dig Interroge un serveur DNS MX serveurs de messagerie
+short réponse courte
@8.8.8.8 choisit le serveur DNS
nslookup / host Résolution DNS simple —
nmap Scanne les ports d'une machine -p 80,443 choisit les ports
-sV détecte les versions des services
-sn détecte les machines actives
tcpdump Capture et analyse les paquets réseau -i eth0 choisit l'interface
-n sans résolution de noms
port 80 filtre sur un port
arp Affiche la table ARP (correspondance IP / adresse MAC) -a affiche toutes les entrées
ssh Se connecte à une machine distante de façon sécurisée -p 2222 choisit le port
-i cle.pem utilise une clé privée
Téléchargement et transfert de fichiers
wget Télécharge un fichier depuis un serveur web -O nom choisit le nom du fichier
-c reprend un téléchargement interrompu
-r télécharge récursivement
curl Envoie des requêtes HTTP et transfère des données -O enregistre le fichier
-I affiche seulement les en-têtes
-L suit les redirections
-o nom choisit le nom du fichier
scp Copie des fichiers vers/depuis une machine distante via SSH -r copie un dossier
-P 2222 choisit le port
rsync Synchronise des dossiers (local ou distant) -a mode archive (conserve droits et dates)
-v mode verbeux
-z compresse pendant le transfert
--delete supprime ce qui n'existe plus dans la source
Compression et archives
tar Regroupe des fichiers dans une archive (et la compresse) -c crée une archive
-x extrait une archive
-t liste le contenu
-v mode verbeux
-f nom du fichier archive
-z compression gzip (.tar.gz)
-j compression bzip2 (.tar.bz2)
gzip / gunzip Compresse / décompresse un fichier au format gzip -k conserve le fichier d'origine
-9 compression maximale

Système
man Affiche le manuel d'une commande q quitter
/mot rechercher dans le manuel

-r version du noyau

shutdown Éteint ou redémarre le système -h now arrêt immédiat

apt upgrade Met à jour les paquets installés -y répond « oui » automatiquement
apt install Installe un paquet -y répond « oui » automatiquement

apt search Recherche un paquet dans les dépôts —

apt autoremove Supprime les paquets devenus inutiles —
dpkg Gère les paquets .deb directement -i fichier.deb installe un paquet
-l liste les paquets installés
-r supprime un paquet
