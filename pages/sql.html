Introduction à SQL

SQL (Structured Query Language) est le langage standard pour interroger et gérer les bases de données relationnelles. Il permet de créer des tables, d'insérer, de modifier, de supprimer et de rechercher des données. Il est utilisé avec des systèmes comme MySQL, PostgreSQL ou SQL Server.
